# Configuration Reference

## Configuration Files

| File | Description | gitignored |
|------|-------------|-----------|
| `.maw/config.json` | Project configuration | ✓ |
| `.maw/state.json` | Workspace state | ✓ |
| `.maw/claims.json` | File exclusive claims | ✓ |
| `.maw/lockfile-hash` | Lockfile SHA-256 | ✓ |
| `.maw/handovers/ws-<name>.md` | Handover documents | ✓ |

---

## `.maw/config.json`

Project configuration file generated by `maw init`.

### Schema

```json
{
  "version": 1,
  "ecosystem": "nodejs",
  "packageManager": "yarn",
  "symlinkDirs": ["node_modules"],
  "copyFiles": [".env", ".envrc"],
  "validationCommand": "yarn lint && yarn compile && yarn test",
  "github": {
    "owner": "your-org",
    "repo": "your-project"
  }
}
```

### Fields

#### `version` (integer, required)

Configuration schema version. Always `1` in the current version.

#### `ecosystem` (string, required) — added in v0.4.0

The project ecosystem. Auto-detected by `maw init`.

| Value | Detection condition | Default symlinks |
|-------|-------------------|-----------------|
| `nodejs` | `package.json` exists | `["node_modules"]` |
| `python` | `pyproject.toml` or `requirements.txt` exists | `[]` |
| `rust` | `Cargo.toml` exists | `["target"]` |
| `go` | `go.mod` exists | `[]` |
| `generic` | none of the above | `[]` |

Can be overridden manually.

#### `packageManager` (string, optional)

Used only for `nodejs` ecosystem. Specifies which package manager to use.

| Value | Detected from |
|-------|--------------|
| `yarn` | `yarn.lock` |
| `npm` | `package-lock.json` |
| `pnpm` | `pnpm-lock.yaml` |
| `bun` | `bun.lockb` |

#### `symlinkDirs` (string[], optional)

Directories to symlink when creating a workspace.

```json
"symlinkDirs": ["node_modules", ".venv"]
```

Each entry is relative to the repository root.
Use `maw spawn --isolated` to install independently instead of symlinking.

#### `copyFiles` (string[], optional)

Files to copy into each workspace on creation. Useful for environment-specific files like `.env`.

```json
"copyFiles": [".env", ".envrc"]
```

#### `validationCommand` (string, optional)

Command for quality checks. Used by `maw doctor` and CI integrations.

```json
"validationCommand": "yarn lint && yarn compile && yarn test"
```

#### `github` (object, optional)

GitHub integration info. Used for future features (issue linking, etc.).

```json
"github": {
  "owner": "your-org",
  "repo": "your-project"
}
```

## `.maw/state.json`

Tracks the state of all workspaces. **Direct editing is discouraged** (use `maw doctor --fix` to repair).

### Schema

```json
{
  "workspaces": {
    "feature-auth": {
      "name": "feature-auth",
      "branch": "claude/feature-auth",
      "agent": "claude",
      "issue": "42",
      "created": "2026-02-20",
      "path": "/path/to/.maw-workspaces/feature-auth"
    }
  }
}
```

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Workspace name |
| `branch` | string | git branch name |
| `agent` | string | Agent type (empty string if not specified) |
| `issue` | string | Issue number (empty string if not specified) |
| `created` | string | Creation date (YYYY-MM-DD) |
| `path` | string | Absolute path to the worktree |

## `.maw/claims.json`

Manages file exclusive claims. **Direct editing is discouraged**.

### Schema

```json
{
  "claims": {
    "src/auth.ts": {
      "workspace": "feature-auth",
      "agent": "claude",
      "claimed_at": "2026-02-20T10:00:00Z",
      "expires_at": "2026-02-20T11:30:00Z"
    },
    "src/components/": {
      "workspace": "bugfix-login",
      "agent": "codex",
      "claimed_at": "2026-02-20T09:00:00Z",
      "expires_at": null
    }
  }
}
```

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `workspace` | string | Workspace holding this claim |
| `agent` | string | Agent type that made the claim |
| `claimed_at` | string | Claim timestamp (ISO 8601 UTC) |
| `expires_at` | string \| null | Expiry timestamp (ISO 8601 UTC). `null` means no expiry |

## `.maw/lockfile-hash`

Stores the SHA-256 hash of the lockfile (`yarn.lock` / `package-lock.json` / `pnpm-lock.yaml` etc.).

Used by `maw doctor` to detect dependency drift — when the lockfile has changed but symlinked workspaces haven't been updated.

## `.maw/handovers/ws-<name>.md`

Human-readable handover document generated by `maw handover`.

### Structure

```markdown
# Handover: feature-auth

Generated: 2026-02-20 10:30:00

## Workspace Info
- Branch: claude/feature-auth
- Agent: claude
- Issue: #42

## Recent Commits
(git log --oneline)

## Changed Files
(git diff --name-status)

## Uncommitted Changes
(git status --short)

## Claims
(list of claims for this WS)

## Notes
(free-form notes placeholder)
```

---

## Environment Variables

maw does not support configuration via environment variables (by design).
All configuration belongs in `config.json`.

---

## .gitignore Integration

`maw init` automatically appends to `.gitignore`:

```gitignore
# maw
.maw/
.maw-workspaces/
```

These directories contain repository-specific runtime metadata and workspace artifacts that should never be committed.
